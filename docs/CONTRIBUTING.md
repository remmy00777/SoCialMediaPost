# Contributing

1. Create a focused branch.
2. Never commit `.env`, tokens, credentials, cookies, databases, generated private media, or backups.
3. Add tests for behavior changes.
4. Run formatting, linting, type checking, backend tests, media tests, secret scan, dependency audit, and the demo workflow.
5. Document every platform API assumption and link to the official source.
6. Do not add scraping, moderation bypass, fake engagement, account impersonation, unauthorized cloning, or unlicensed asset use.
7. Keep safety gates human-reviewable and versioned.
