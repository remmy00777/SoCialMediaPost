# Changelog

## 0.2.0, 2026-08-01

- Added irreversible content-package deletion with byte and file recovery reporting.
- Added multiple connected platform accounts per application user and account-specific publication targeting.
- Added rights-managed source-media uploads with ownership or license declarations.
- Added a local voiceover-intro renderer that plays the complete authorized source clip after the introduction.
- Added source-media validation, duration and size limits, compliance-report declarations, portal controls, and regression tests.
- Added `espeak-ng` to the container image as the default local voiceover fallback.

## 0.1.0, 2026-07-30

- Added local-first FastAPI, PostgreSQL, Redis, Celery, FFmpeg, and macOS launchd architecture.
- Added platform adapter contracts and official-access eligibility gates.
- Added discovery, scoring, analysis, original content generation, media rendering, package storage, policy and originality checks.
- Added local portal and optional Next.js portal source.
- Added demonstration workflow, analytics, experiments, reports, backups, notifications, cost controls, tests, scripts, and documentation.
